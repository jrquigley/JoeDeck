# Changelog

## 3.1.2
- Optional label in the corner of the screen showing the sign's Wi-Fi address (Display → Other → "Show Wi-Fi address on screen")

## 3.1.1
- Fix: black screen on Raspberry Pi OS Trixie when no keyboard/mouse is plugged in (display now starts without input devices)
- Wi-Fi power saving turned off so signs stay reachable over Wi-Fi

## 3.1
- Shared media library: upload once, use on every sign (files copied between signs automatically)
- Groups: several signs show the same content and change items at the same moment (lockstep), including shuffle and schedules
- Only admins or the uploader can rename/delete shared items

## 3.0
- Websites as media (zoom, auto-reload), shown inside slideshows alongside images
- Transition styles (fade, slide, instant) and shuffle per playlist
- Wi-Fi: set during install, manage per sign in the web page, or save a network on all signs at once
- Install: one command; asks for sign name, Wi-Fi, and joins existing signs automatically
- Updates: signs check GitHub for new versions; update one or all signs with a click
- Published on GitHub with automatic release builds

## 2.1
- Mouse pointer hidden on the sign; single-file installer

## 2.0
- Multiple signs on one network, users and permissions, activity log

## 1.0
- First version: images, playlists, schedules, orientation
